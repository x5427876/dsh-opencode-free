# Triage labels

Use these five native GitHub labels; skill role names map directly to them.

| Label | Meaning |
|---|---|
| `needs-triage` | Maintainer evaluation needed |
| `needs-info` | Waiting for reporter information |
| `ready-for-agent` | Fully specified work an Agent can implement |
| `ready-for-human` | Human action required |
| `wontfix` | Will not be actioned |

Preserve existing labels and settings; create only missing labels when asked.
Open/closed state and assignees track progress separately. Claim and completion
steps are in the [issue workflow](issue-tracker.md).
