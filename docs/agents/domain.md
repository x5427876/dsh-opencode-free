# Domain documentation

This is a single-context repository.

1. Read root [CONTEXT.md](../../CONTEXT.md) for domain vocabulary when exploring
   or naming behavior.
2. Read only the ADR relevant to the change: session identity (0001), runtime
   catalogue (0002), live verification policy (0003), or acceptance targets (0004).
   The [documentation index](../README.md#decisions) links to each.
3. If a change conflicts with an accepted ADR, identify the conflict and resolve
   the decision explicitly rather than silently changing policy.

CONTEXT is a glossary, not a spec or implementation log. ADRs hold lasting
trade-offs; current requirements and work state live in GitHub Issues.
Read archived investigations only when tracing a specific historical claim.
