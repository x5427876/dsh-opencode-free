# 官方模型清單是免費模型的唯一來源

**Status**: accepted, 2026-10-30. 部分取代 [ADR-0002](0002-catalogue-source-of-truth.md)
（資料來源與快取）與 [ADR-0004](0004-official-dynamic-compat-targets.md)（目標分類方式）。

外掛選單與相容性驗證都以官方 `/inference/v1/models` 判定「哪些模型存在且免費」，
不再使用 models.dev 或文件頁價格表決定成員。該清單現在每項都帶價格、端點通道、
上下文上限、模態與推理等級，所以一份回應就能分類並建出模型記錄；ADR-0004 寫下
「官方目錄未提供費率或通道欄位」的前提已不成立。

## 決策

- **官方免費清單**：`type` 為 `chat`，且 `cost.text` 的 input、output 與已宣告的
  cache 價格皆為 0。術語見 [CONTEXT.md](../../CONTEXT.md)。
- 外掛能力資料（上下文、輸出上限、輸入模態、推理等級、通道、`reasoning_content`
  回傳要求）取自同一筆官方記錄。官方未發布的欄位不猜測。外掛執行期不再下載 models.dev。
- 在列只代表可能可用。探測與 `ok`、`dead`、`inconclusive` 的語意不變，仍依 ADR-0002。
- 更新只有一條 30 分鐘的惰性軸，單一寫入者。官方回應沒有 ETag 且標 `no-store`，
  每次約 94KB 完整下載。
- 回應失敗、非 2xx、空清單、或沒有任何項目帶可解析價格時，視為結構變更：保留上次
  成功的清單。單一項目價格缺失或非數字，只將該項目視為非免費。結構正常但免費項目為零，
  照實顯示空清單。
- 快取保存上次成功的免費項目、探測判定與輪次摘要。舊版快取的判定與摘要沿用，舊的
  models.dev 資料與 ETag 丟棄。沒有快取又取不到清單時，選單為空；pi-ai 內建清單只
  提供身份範本，不再當兜底清單。
- 被官方下架或轉為付費的模型從選單隱藏，其探測判定保留，重新列出時恢復。
- 相容性驗證讀同一端點，但由獨立程式分類，不共用外掛目錄程式碼，並驗證外掛選單與
  官方免費集合相等，多出或缺少都是 `plugin-fault`。文件頁價格表降為交叉檢查：與官方
  清單不一致只產生警示，不改變目標。報告保存官方清單的快照摘要（時間、總數、免費
  id、內容摘要）。

## 取捨

只信一個來源，就讓官方資料出錯時直接影響選單，所以保留文件頁的交叉檢查警示，並對
結構變更採保守處理。該端點沒有公開的穩定性承諾，只有實測；每輪驗證存快照摘要，以便
追查異動。models.dev 的資料有更新延遲，且與官方曾互相矛盾（`nemotron-3-ultra-free`
在文件頁與 `opencode models` 都有，官方清單沒有），保留它只會增加來源衝突。
