# 相容性驗證不進 CI，429 一律算「不確定」

相容性驗證（compat run）只在開發者本機手動跑，不接 CI；`rate-limited`（上游 429）
既不算通過也不算失敗，只有 `plugin-fault` 讓退出碼為 1。匿名額度按出口 IP 共用，
CI 的共用 IP 讓匿名 bucket 幾乎必然是乾的，結果沒有意義；把 429 算失敗，
流程會永遠是紅的，開發者學會忽略它。

**Status**: accepted

**Considered Options**:
- 進 CI、429 算失敗：自動化，但結果取決於同一出口 IP 上別人的用量，不可重現。
- 進 CI、429 算通過：永遠綠，等於沒驗。
- 本機手動、429 算不確定（採用）：結果只反映「這台機器此刻能證明什麼」，
  代價是靠開發者在升級 DSH 時記得跑（寫進 `AGENTS.md` 的升級流程）。

**Consequences**: 有 `rate-limited` 或未驗證的模型時退出碼為 2，
意思是「沒壞，但沒驗完，稍後再跑」，和 `plugin-fault` 的 1 區分。
若日後 Zen 提供可供 CI 使用的測試 key 或獨立額度，重審本決策。
探測（probe）的範圍見 ADR 0002，不在此重複。
