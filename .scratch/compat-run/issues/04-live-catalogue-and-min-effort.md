# 04: 即時模型清單、清單差異與最低 effort 等級

Spec: `../spec.md`
ADR: `docs/adr/0002-catalogue-source-of-truth.md`

## What to build

讓相容性驗證驗的是「Zen 現在提供的全部免費模型」，並用每個模型自己的最低思考等級送請求。

- 模型清單取自即時資料：Zen 的模型列表與 models.dev 標為免費者的交集，經注入的依賴取得，這樣剛上架、外掛內建清單還沒更新的模型也會被驗到。
- 報告列出「內建清單有、即時清單沒有」的模型，也列出相反方向的差異。
- 每個模型取它發布的最低 effort 等級作為驗證用的思考等級，並記入報告。
- 沒有發布等級的模型（toggle 型或沒有清單）用預設，並在報告標示「無等級可選」，表示該模型沒驗到 reasoning 轉換。

## Acceptance criteria

- [ ] 清單為 Zen 列表與 models.dev 免費者的交集
- [ ] 即時清單新增的模型出現在驗證對象中
- [ ] 內建清單有、即時清單沒有的模型出現在報告的差異區
- [ ] 有發布等級的模型使用其最低 effort 等級，且報告記錄該等級
- [ ] 沒有發布等級的模型使用預設並標示「無等級可選」
- [ ] 取得即時清單失敗時，行為明確且報告說明（不得靜默退回內建清單而不告知）
