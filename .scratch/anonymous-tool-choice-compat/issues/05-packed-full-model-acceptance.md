# 05: 打包並完成隔離 DSH 全模型相容性驗收

**Parent:** [功能規格](../spec.md)。

**What to build:** 以整合後的本地插件產物，在隔離 DSH 0.2.1-alpha.3 中對官方動態在列的所有免費對話模型完成 L0／L1／read／pwsh 驗收，留下能核對的成功證據。若上游或資料狀態讓驗收未完成，保留真實結果，維持尚未達成的完成狀態。

**Blocked by:** 01「修復無工具匿名請求並守住宿主執行邊界」；04「讓每層結果、完整範圍與退出碼一致」。02、03 為經由 04 傳遞的相依，不重複列為直接 blocker。

**User stories:** 25、34、39–44；整合驗證全部 1–44。

## Acceptance criteria

- [x] 前置票已完成，且整合後的型別、離線行為測試、建置與打包檢查通過。驗證實際 tarball 的執行匯入、型別、client 與 patch／exports 可用，並排除憑證、快取、私有 scratch 與診斷資料。
- [x] 保留本地插件版本 0.3.4 與精確 DSH 0.2.1-alpha.3。核對實際安裝的 CLI、adapter／pi-ai 版本，將本地工作樹產物與已發布同版本清楚區分。
- [x] 執行前依當時對話核對明確 live 授權。已有涵蓋本輪的授權即沿用；未有授權時先完成全部離線與產物準備，再說明缺少授權。發布或核准拆票本身不表示執行 live；不擅自新增輪次。
- [x] 經既有 pnpm 相容性驗證入口執行完整範圍，啟用工具，省略單模型限制，使用獨立報告位置。開跑前重新取得官方動態目標、來源時間、排除與未確認證據。
- [x] 使用暫存 DSH_HOME、工作目錄、內建 headless 與 overlay，安裝本輪 tarball，限定匿名 public。只在測試子進程移除 key 與 debug 設定；帶 key 對照不取代匿名結果。
- [ ] 每個非空目標集合中的模型均在同一輪通過 L0 目錄／探測、L1 真實 DSH 非空文字、L2 指定 read nonce 與 Windows pwsh 隨機檔案雜湊。工具步驟有呼叫、參數、配對結果與 final 證據。
- [x] 報告保存完整範圍、各層安全判定、環境、來源版本及退出碼。原始事件、對話、推理、工具輸入／結果、憑證與 request body 不落盤。
- [x] 403、429、逾時、上游不可用、來源未確認或未驗證模型都如實報告。保留有限退避與停止規則；不藉換模型、刪失敗列、反覆安裝或跨輪合併結果達成全部通過。
- [x] 完整目標未全數通過時，本票不能標記 resolved 或宣稱規格完成。清楚記錄阻礙、已完成證據、未驗證項與後續所需條件；不將額度或上游未完成誤稱為已確認插件故障。
- [x] 成功或失敗後清理本輪暫存環境並檢查清理結果。既有 DSH 程序、profile、憑證、無關插件與預先存在檔案保持不變。
- [x] 對照全部使用者故事與驗收基準檢查整合差異，處理本次造成的缺口，更新實際結果與限制。不要升級版本、打 tag、發布、安裝到使用者 profile，或將 headless 成功擴張成 Web／Desktop／compaction／跨平台成功。
